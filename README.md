# Dynamic Excel Receipt Template

## Overview
This repository contains a smart, automated receipt template built in Microsoft Excel, along with a screen recording demonstration. It is designed to make billing and financial documentation quick, accurate, and professional.

## ✨ Key Features
* **Automated Calculations:** Uses built-in Excel formulas to instantly calculate line-item totals based on quantity and unit price.
* **Dynamic Tax Rates:** Easily adjust the tax percentage, and the sheet will recalculate the entire bill automatically.
* **Professional Layout:** Clean, corporate design ready to be printed or exported as a PDF for clients.
* **Time-Saving:** Eliminates the need for manual math, reducing errors in financial records.

## 🛠️ How to Use
1. Download the Excel file (`.xlsx`) from this repository.
2. Open the file in Microsoft Excel.
3. Update the **Customer Details**, **Receipt #**, and **Date**.
4. Enter your items under the **Description** column.
5. Adjust the **Qty** (Quantity) and **Unit Price** for each item. The `Amount` will update automatically.
6. Set your desired **Tax Rate** at the bottom, and the `Grand Total` will be calculated for you.
